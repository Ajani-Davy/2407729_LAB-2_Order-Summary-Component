## Deployment to GitHub Pages

Because this project uses standard relative paths and static HTML/CSS, it deploys directly to GitHub Pages with no build step or server required:

1. Push this directory to your GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Order Summary Component"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
2. On GitHub, navigate to **Settings** > **Pages**.
3. Under **Build and deployment** > **Source**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then click **Save**.
5. Your live site will be accessible at:
   `https://<your-username>.github.io/<your-repo-name>/`
